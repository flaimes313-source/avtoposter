# Telegram Autoposter Bot

Бот для автоматического постинга контента в Telegram-каналы по расписанию.

## Возможности
- Создание отложенных постов (картинка/GIF/текст)
- До 3 ссылок в посте
- Эмодзи в тексте
- Отдельные рекламные посты для других каналов
- SQLite база данных
- Деплой на Bothost

## Установка
1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте `.env` с токеном бота
4. Запустите: `python main.py`
